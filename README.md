# Library Commerce Rest API - Microservice 

## Sobre Library

Microsserviço de API de livraria com metodos CRUD (Create, Read, Update e Delete) para simular uma loja virtual de livros. É responsável pela transição de dados refentes aos livros e clientes. Para autenticação e histórico de pagamento, será utilizado outros microsserviços. Está sendo desenvolvido em Java e Spring Boot e foi construído com o intuito de treinar mais sobre o backend e suas tecnologias, em conjunto com um tema importante, que é o ecommerce, além, claro, da leitura.

## Funcionalidades
- Criar um Livro
- Listar todos os livros
- Criar um cliente
- Retornar um cliente
- Editar cliente;
- Excluir cliente;
- Editar o livro
- Excluir Livro
