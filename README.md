# Library Commerce Rest API 

## Sobre Library

API de livraria com metodos CRUD (Create, Read, Update e Delete) para simular uma loja virtual de livros. Está sendo desenvolvido em Java e Spring Boot e foi construído com o intuito de treinar mais sobre o backend e suas tecnologias, em conjunto com um tema importante, que é o ecommerce, além, claro, da leitura.


## Instalação
Para a instalação, basta ter um IDE de sua preferência, carregar as dependências do Spring, que no caso está sendo gerenciado pelo Maven, e aproveitar!
